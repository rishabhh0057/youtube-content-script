
# 🎬 AI-Powered YouTube Content Script Generator

An AI application built with **Streamlit** and **Google Gemini AI** that generates fully structured, high-retention YouTube scripts containing spoken dialogue, visual instructions, and calls-to-action.

## 🌟 Features
- **Tailored Formatting:** Automatically splits scripts into visual cues, spoken dialogue, intro hooks, and CTAs.
- **Custom Parameters:** Select video length, tone, target audience, and specific takeaways.
- **BYO API Key:** Completely free to deploy and use by using your Google AI Studio API key.
- **Export Ready:** One-click script download functionality.
